Course Notes

HTML Basics

HTML stands for HyperText Markup Language. It gives a webpage its structure.
It's a markup language, not a programming language, so it just labels stuff on the page.

Some tags I've learned so far: headings (h1 - h6), paragraphs (p), line breaks (br), links (a), images (img), buttons, and inputs.

Want to learn more? Check out MDN's HTML guide.

JavaScript Basics

JavaScript is what makes a webpage actually do stuff. HTML is the structure, CSS is the looks, and JS is the behavior.

Some things I've learned: let and const for variables, functions, if statements, querySelector() to grab stuff off the page, and addEventListener() to run code when you click something.
